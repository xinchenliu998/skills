# Screenshot 截图

<!-- source: https://handyorg.github.io/handycontrol/extend_controls/screenshot/ -->

可通过快捷键触发，将整个屏幕或者指定区域内容保存为图片.

```csharp
public class Screenshot
```

## 方法

| 名称 | 说明 |
| --- | --- |
| Start( ) | 开始截图 |

## 事件

| 名称 | 说明 |
| --- | --- |
| Snapped | 截图完成时触发 |

## 案例

```csharp
new Screenshot().Start();
```
