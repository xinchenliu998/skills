# 杂光检测编排入口 (基于F50V05AA规格V1.0)

## ⚠️ 核心评判标准（来自 F50V05AA杂光V1.0.xlsx）

### 检测目标
**不是全局图像质量判定，而是逐个光源的"光刺"长度检测！**

### 基本参数
- 模组型号: F50V05AA
- 图像尺寸: 2624×2624 (binning后)
- 灯源个数: 31pcs（0.85视场14pcs + 0.5视场8pcs + 0.3视场8pcs + 中心1pcs）
- **蓝色圈半径: 180像素**（以每个光源中心为圆心的判定边界）
- 寄存器: 增益3508:0X4F, 曝光LUMINANCE_VAL1=0x03/VAL2=0x00
- 灯源照度: 150±15LUX

### 判定规则（三条规则，缺一不可）
1. **规则1-长度NG**: 任意光源存在一个光刺超出蓝色圈(半径180px) → **NG**
2. **规则2-数量NG**: 全部光源允许存在三个不超过蓝色圈的光刺；≥4个光刺 → **NG**（不区分内外圈）
3. **规则3-形态**: 光刺只管控长度，亮度差不管控

### NG分类
| NG类型 | 描述 | 判定依据 |
|--------|------|---------|
| 长度NG | 光刺超出蓝色圈范围(>180px) | 规则1 |
| 数量NG | 全视场≥4个光源存在光刺（即使都不超蓝色圈）| 规则2 |
| 异型光斑NG | 灯源有异型光斑(非正常圆形/方形) | 限度样品② |

### OK边界（限度样品）
| OK极限类型 | 描述 |
|-----------|------|
| 极限OK① | 光源周围有发散形刺状杂光，但长度不超蓝色圈且光刺数≤3个 |
| 极限OK② | 光源模糊变形（非光刺，是模糊），极限OK品 |

## 检测流程（按需加载各step skill）

### Step 0: 图像预处理
- 读取图像 (2624×2624 binning JPG)
- 转灰度，计算全局统计（均值、高亮比例等，仅供参考）
- skill文件: `skill/stray_light_step0_preprocess.md`

### Step 1: 光源定位与特征提取
- **关键步骤**: 定位所有31个光源的中心坐标
- 方法: 阈值分割 → 连通域 → 面积/形状筛选正常光斑
- 提取每个光源的：中心(row, col)、面积、圆度、凸度
- 输出光源列表: List<SpotInfo> 包含 (id, centerRow, centerCol, area, circularity)
- skill文件: `skill/stray_light_step1_spot_detection.md`

### Step 2: 逐光源光刺检测（核心步骤）
- **最关键步骤**: 对每个光源，检测其周围的"光刺"并测量长度
- 算法流程:
  1. 以光源中心为圆心，取ROI区域（半径~250px的圆）
  2. 减去光源核心区域（正常光斑的膨胀区域）
  3. 在环形区域内用动态阈值检测放射状亮区（光刺候选）
  4. 对每个光刺候选，计算其从光源中心的最大径向距离(maxRadialDist)
  5. **判定**: maxRadialDist > 180px → 该光源"长度NG"
  6. 记录每个光源是否有光刺、光刺最大长度
- 光刺检测方法（推荐组合使用）:
  - **极坐标展开**(PolarTransImage): 将以光源为中心的环形区域展开为矩形，光刺变为水平方向更易检测
  - **动态阈值**(DynThreshold): 提取局部异常亮区
  - **形态学筛选**: 选择长宽比大的线状区域作为光刺
  - **径向距离计算**: 对检测到的光刺区域，计算其最远点到光源中心的距离
- skill文件: `skill/stray_light_step2_stray_classify.md`

### Step 3: 光斑形态分析（异型光斑检测）
- 对每个光源的光斑形状进行分析
- 正常光斑应近似圆形/方形
- 指标: 圆度(circularity)、凸度(convexity)、矩形度(rectangularity)
- 圆度过低 + 面积异常 → 异型光斑NG
- skill文件: `skill/stray_light_step3_fft_analysis.md`

### Step 4: 综合判定
- **规则1**: 任意光源光刺长度>180px → NG（长度NG）
- **规则2**: 全视场光刺数量≥4个（即使都≤180px）→ NG（数量NG）
- **规则3**: 存在异型光斑 → NG（异型NG）
- **OK判定**: 光刺数≤3个 且 所有光刺长度≤180px 且 无异型光斑
- 输出: OK/NG判定 + 置信度 + 光刺标注图 + 详细报告
- skill文件: `skill/stray_light_step4_judgment.md`

## 与旧算法的根本差异

| 维度 | 旧方法（全局统计） | 新方法（逐光源检测） |
|------|-------------------|---------------------|
| 分析单元 | 整张图像 | 每个光源单独分析 |
| 检测目标 | 全局亮度/纹理异常 | 光刺长度+数量+形态 |
| 判定依据 | 灰度统计加权评分 | 光刺是否超180px蓝色圈 |
| 核心算法 | 直方图/GLCM/FFT/标准化偏差 | 极坐标展开+动态阈值+径向距离 |
| 数量规则 | 无 | ≤3个光刺OK，≥4个NG |
| 亮度依赖 | 高度依赖灰度绝对值 | 不管控亮度差，只管控长度 |

## 关键实现要点
1. **光源定位精度是基础**: 必须准确找到31个光源的中心坐标
2. **光刺长度测量是核心**: 不是面积，是"径向距离"
3. **180px是唯一的长度阈值**: 来自标准文件的蓝色圈半径
4. **3个是数量阈值**: ≤3个OK，≥4个NG（当前已禁用，不可靠）
5. **不看亮度差**: 光刺只管控长度，亮度差不管控

### 调优经验总结（v13→v22，10+版本迭代）
- **反光胶布过滤是关键突破**: 图像边缘80px带状区域检测灰度>200高亮+膨胀30px排除
- **光刺标准不宜太松**: aniso<3.5或ratio<1.6导致FP飙升
- **异型光斑门槛要极严**: circ<0.08才是真异型(0.43/0.72都是正常光斑！)
- **邻居光源排除是关键**: 相邻光源光晕是FP主因，用3倍半径排除
- **多重验证缺一不可**: 面积+aniso+灰度对比+径向跨度+角度宽度+核心连接
- **微调放松不一定有效**: v22比v21松一点,FP多2个但TP不变

### 可视化规则
- NG判定 → 红色圈 (255,0,0)
- OK判定 → 绿色圈 (0,200,0)
- 异型光斑 → 橙色圈 (255,128,0)
