# Step 4: 综合判定 v17

## 判定规则（按优先级）

### 规则1: 光刺长度NG
- 条件: 任意光源的MaxSpikeLength > 180px（蓝色圈半径）
- 原因: `长度NG: 光刺超出蓝色圈`

### 规则2: 异型光斑NG
- 条件: 任意光源 Circularity < 0.25 且 Convexity < 0.5
- 或: 面积比>3.0(或<0.15) 且 Circularity < 0.3
- 原因: `异型光斑NG: N个光源形状严重异常`

### OK判定
- 无光刺且无异型 → 置信度98%
- 有光刺但未超出蓝色圈 → 置信度递减
